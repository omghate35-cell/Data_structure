# Data Structures Assignment Collection

A comprehensive collection of data structure and algorithm implementations covering fundamental computer science concepts.

## 📋 Assignments Overview

### Assignment 1
Basic data structure fundamentals and introduction to Python implementation.

### Assignment 2 - Sorting Algorithms
Implementation of fundamental sorting algorithms:
- **Bubble Sort** (`assignment-2 Bubble sort.py`) - Simple comparison-based sorting algorithm
- **Insertion Sort** (`assignment-2 Insertion sort.py`) - Efficient for small datasets
- **Selection Sort** (`assignment-2 Selection sort.py`) - In-place sorting with predictable performance

### Assignment 3 - Advanced Sorting
Efficient divide-and-conquer sorting algorithms:
- **Merge Sort** (`assignment-3 Merge sort.py`) - O(n log n) guaranteed time complexity
- **Quick Sort** (`assignment-3 Quick sort.py`) - Average O(n log n) with good practical performance

### Assignment 4 - Singly Linked List
Implementation of singly linked list data structure with common operations.
- File: `assigment-4 Singly linked list.py`

### Assignment 5 - Doubly Linked List
Implementation of doubly linked list with bidirectional traversal capabilities.
- File: `assignment-5 Doubly Linked list.py`

### Assignment 6 - Merge Two Sorted Lists
Algorithm to efficiently merge two sorted lists/arrays.
- File: `assignment-6 Merge two sorted lists.py`

## 🎯 Learning Objectives

- Understand fundamental data structures (arrays, linked lists)
- Master sorting algorithms and their time/space complexity analysis
- Implement and manipulate linked list operations
- Compare algorithm efficiency and trade-offs
- Apply problem-solving techniques to common data structure challenges
